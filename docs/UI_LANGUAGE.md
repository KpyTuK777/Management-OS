# UI Language

This legacy documentation path is retained for compatibility.

The canonical standard for Ukrainian interface terminology, writing style,
component naming, and future AI communication is the
[Product Language Guide](PRODUCT_LANGUAGE.md).

Operational Situation Board naming and reasoning-change language are governed by
the Product Language Guide and the
[Operational Situation Board Architecture](OPERATIONAL_SITUATION_BOARD_ARCHITECTURE.md);
this compatibility path does not redefine them.

For the progressive Investigation prototype, owner-facing prompts use direct
operational language such as “Tell me everything you already know,” “Add what you
know,” “What became clear,” and “What still needs to be found out.” Canonical
architecture names remain available in documentation and specialist inspection,
not as primary task instructions.

The Sprint 20 opening is governed by the
[Human-first Investigation Experience](HUMAN_FIRST_INVESTIGATION_EXPERIENCE.md).
Primary Watson messages use short operational questions and revisable summaries.

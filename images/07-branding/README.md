# Branding

## Purpose

Define recognizable product identity without separating brand expression from operational work.

## Questions answered

- What is distinctly Management OS?
- How should the mark behave at Dock scale?
- Which qualities must recognition convey?

## Supports

Maturity, precision, quiet confidence, permanence, and emotional recognition.

## Belongs here

Mark studies, monograms, wordmarks, identity proportions, and approved usage contexts.

## Avoid

Generic technology symbols, decorative complexity, fashionable gradients, mascot behavior, and identity that competes with the Workbench.

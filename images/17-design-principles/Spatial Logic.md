# Spatial Logic

Position is meaning.

Proximity suggests relevance; grouping suggests shared role; connectors state explicit interpretation. Therefore, spatial decisions require the same discipline as language. Items are not connected automatically, and temporal sequence does not imply causality.

The map must preserve stable context across inspection, collection navigation, contribution, and refresh. New understanding may grow the composition without erasing the owner’s spatial memory.

Every connector must name its semantics: influence, mutual dependency, support, contradiction, temporal relation, or tentative proposal.

# Visual Hierarchy

## Purpose

Visual hierarchy directs attention according to operational importance.

Management OS should make the current subject, its supporting context, and the next relevant judgment understandable before the owner reads every element.

## Principle

Position, scale, contrast, spacing, and material must express a clear order of attention.

Hierarchy is not decoration. It is the visual form of operational priority.

## Unified Attention

Every major interface component should reinforce the current investigation.

No element should demand equal attention to the primary subject.

Supporting panels exist to deepen understanding, not to distract from it.

When several interface elements are visible simultaneously, the eye should still return naturally to the Current Situation.

The Workbench should always communicate one investigation, one center, one flow of attention.

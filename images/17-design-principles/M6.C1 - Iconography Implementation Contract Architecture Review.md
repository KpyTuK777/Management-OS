# 4. Preservation and Ambiguity Review

Resolution is deterministic for identical sources, definition, context,
subject snapshot, and capability. Unresolved or conflicting input fails closed.

Symbols create no truth, identity, authority, priority, state, relationship,
causality, confidence, provenance, eligibility, consequence, or history.
Independent dimensions remain separately sourced. Modifiers cannot change
primary meaning. Composition cannot create relationships through proximity,
overlap, containment, or sequence.

Reuse requires identical definition meaning, unambiguous context, explicit
qualifiers/equivalents, separate definitions for different meanings, and
negative ambiguity evidence. Glyph equality proves no semantic equality.
Ambiguous use falls back to a non-symbolic equivalent or safe unavailability.

**Result: Pass.**

---

# 5. Accessibility, Degradation, and Recovery

Every occurrence includes textual, non-visual, or alternative-modality
equivalence preserving subject, meaning, qualifiers, status/state, provenance,
authority, uncertainty, interaction, navigation, degradation, and operation.
Symbol-only interpretation is prohibited for consequential use.

Absence is not semantic absence. Unsupported realization resolves an approved
equivalent, preserves structure/order, discloses degradation, blocks only unsafe
operation, rejects generic/vendor substitution, retains continuity, and
recovers only from exact definition/mapping/capability with atomic replacement.

Cross-platform equivalence requires equal professional interpretation and
operation, not equal appearance.

**Result: Pass.**

# 6. Lifecycle and Governance

Registration creates no approval. Publication requires approved sources,
complete category applicability, M6.14 mapping, positive and negative M6.15
evidence, independent qualification, and atomic publication.

Binding/context/modifier/composition/equivalent/fallback change creates a new
revision. Extensions cannot overload meaning. Deprecation preserves obligations
and history; migration maps all identities/obligations and blocks mixed
revisions; withdrawal preserves provenance; correction never rewrites history;
material changes require requalification.

**Result: Pass.**

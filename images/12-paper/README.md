# Paper

## Purpose

Define working-document surfaces for situations, notes, reports, and notebook capture.

## Questions answered

- Which paper qualities distinguish authored work from interface chrome?
- How do age, edge, line, and shadow remain restrained?
- How is text kept readable?

## Supports

Authorship, editability, evidence handling, warmth, and working continuity.

## Belongs here

Paper tone, weight, ruling, edge, fold, pinning, and shadow references with clear roles.

## Avoid

Scrapbook styling, torn-paper spectacle, unreadable stains, arbitrary rotation, and using paper for every container.

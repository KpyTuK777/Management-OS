# Icons

## Purpose

Define a coherent recognition system for navigation, operational material, state, and action.

## Questions answered

- Which geometry and stroke belong to the product?
- How is item type recognized before reading?
- What text equivalent preserves accessibility?

## Supports

Rapid orientation, semantic consistency, accessibility, and visual quiet.

## Belongs here

Icon-family studies, semantic mappings, sizing, optical alignment, stroke rules, and state behavior.

## Avoid

Mixed families, emoji as final product language, color-only meaning, inconsistent weights, ambiguous metaphors, and ornamental icons.

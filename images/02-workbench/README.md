# Workbench

## Purpose

Design the place where operational thinking happens.

## Questions answered

- Where should attention go?
- How should reasoning and evidence coexist?
- How much empty space is healthy?
- How should the workspace grow with understanding?
- How should owners feel while studying a situation?

## Supports

Focus, orientation, comparison, spatial memory, confidence, and sustained reasoning.

## Belongs here

References to the Workbench as a whole. Use the child folders for room, desk, composition, spatial logic, and thinking-process questions.

## Avoid

Dashboards, CRM layouts, equal-weight cards, perfect grids, decorative clutter, permanent assistant columns, and vertical document flows.

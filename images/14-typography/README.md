# Typography

## Purpose

Define a readable editorial voice for operational judgment.

## Questions answered

- Which type roles distinguish synthesis, evidence, metadata, and action?
- How does hierarchy survive dark and paper surfaces?
- What remains readable responsively?

## Supports

Authority, calm, precision, sustained reading, and clear operational hierarchy.

## Belongs here

Type-family studies, scale, weight, line-height, measure, numeral treatment, and contrast examples.

## Avoid

Decorative display type, tiny metadata, excessive uppercase, weak gray text, inconsistent scales, and typography used as ornament.

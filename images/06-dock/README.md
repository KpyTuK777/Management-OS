# Dock

## Purpose

Define navigation as subordinate orientation.

## Questions answered

- What minimum geometry preserves location?
- How do active, hover, focus, and labels behave?
- Which destinations deserve permanent presence?

## Supports

Orientation, continuity, maximum Workbench space, and low visual demand.

## Belongs here

Compact docks, coherent icon families, labels on demand, and restrained active states.

## Avoid

Wide sidebars, mixed icon styles, duplicate destinations, promotional navigation, persistent labels, and attention-seeking motion.

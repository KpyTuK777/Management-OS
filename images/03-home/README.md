# Home

## Purpose

Define the entrance to the operational office and the first allocation of attention.

## Questions answered

- What deserves attention now?
- Which Matter, risk, change, judgment, or transition comes first?
- How is the last working context resumed?

## Supports

Readiness, priority, calm urgency, and immediate return to work.

## Belongs here

Editorial entry compositions, priority surfaces, and references for focused arrival.

## Avoid

Feature catalogues, module dashboards, onboarding instruction, equal widgets, performance theatre, and administrative homepages.

# Objects

## Purpose

Define environmental objects that reinforce professional work without becoming props.

## Questions answered

- Which objects imply investigation, drafting, measurement, or continuity?
- What belongs at the edge of attention?
- When is an object unnecessary?

## Supports

Inhabited professionalism, scale, tactile context, and purposeful atmosphere.

## Belongs here

Pens, clips, rulers, magnifiers, compasses, folders, and other restrained working tools with a stated compositional purpose.

## Avoid

Detective clichés, staged clutter, novelty, objects blocking content, and details with no cognitive or spatial role.

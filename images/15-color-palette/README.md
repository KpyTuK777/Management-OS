# Color Palette

## Purpose

Define restrained color as operational semantics rather than decoration.

## Questions answered

- Which neutrals create the office atmosphere?
- Which accent communicates orientation, support, proposal, risk, or contradiction?
- How is every meaning preserved without color?

## Supports

Clarity, recognition, accessibility, warmth, and disciplined attention.

## Belongs here

Palette studies, contrast pairs, semantic assignments, material interactions, and dark/paper surface tests.

## Avoid

Rainbow categories, branded gradients, color-only state, low contrast, excessive saturation, and accents without meaning.

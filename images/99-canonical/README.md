# Canonical Visual Library

This library contains only approved references that express permanent Management OS visual principles. It is intentionally small.

## Admission rule

A reference may enter only when an approved design decision records:

- the permanent principle it demonstrates;
- the exact qualities that are canonical;
- the qualities that must not be copied;
- the approving authority and date;
- source and usage rights;
- the category and descriptive filename.

Attractiveness, recency, similarity to the current prototype, or stakeholder enthusiasm is insufficient.

## Maintenance

- Never use this folder as a shortlist or moodboard.
- Never overwrite a canonical file with a new version.
- Deprecate through a recorded decision and retain history where required.
- Keep implementation screenshots outside this library unless explicitly approved as permanent references.
- Prefer one decisive reference over ten approximate references.

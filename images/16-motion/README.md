# Motion

## Purpose

Define movement that preserves spatial context and confirms state.

## Questions answered

- What should emerge, move, or settle?
- How does inspection open without losing the map?
- Which motion disappears under reduced-motion preferences?

## Supports

Continuity, orientation, cause-and-effect understanding, and quiet responsiveness.

## Belongs here

Timing studies, focus transitions, drawer behavior, spatial restoration, and reduced-motion equivalents.

## Avoid

Ambient animation, bounce, decorative parallax, long easing, attention capture, and movement that implies false relationships.

# Backgrounds

## Purpose

Define the environmental field behind working material.

## Questions answered

- How does the background frame attention?
- Where should directional light or depth appear?
- How does it remain quiet across viewport sizes?

## Supports

Focus, separation, calm depth, and atmospheric continuity.

## Belongs here

Dark fields, subtle lighting studies, workspace depth, and responsive background behavior.

## Avoid

Hero imagery, scenic illustration, visible stock photography, competing contrast, and backgrounds that imply operational meaning.

# Normative Governance Index

## Structural contract

This directory is reserved for independently reviewed normative M7 governance
definitions. It may contain the future M7.2 Constitution, M7.3 Organizational
Model, M7.4 Development Lifecycle, and M7.5 Autonomous Development Protocol
only when each is separately ordered.

This index owns discovery within the normative artifact class. It defines no
Constitution, Organizational Model, Development Lifecycle, or Autonomous
Development Protocol substance and grants no approval.

## Artifacts

- [M7.2 — Constitution](M7.2%20-%20Constitution.md) — **Canonical / M7.2
  Closed**. Establishes the authoritative constitutional foundation for
  enduring governance authority, principles, precedence, separation,
  invariants, interpretation, amendment constraints, and scope.
- [M7.3 — Organizational Model](M7.3%20-%20Organizational%20Model.md) —
  **Canonical / M7.3 Closed**. Title-independent allocation of
  constitutional functions, responsibility domains, authority, delegation,
  accountability, decision boundaries, and power interaction.
- [M7.4 — Development Lifecycle](M7.4%20-%20Development%20Lifecycle.md) —
  **Canonical / M7.4 Closed**. Authority-state lifecycle with bounded stages,
  gates, correction and re-entry, iteration, invariants, and traceability.
- [M7.5 — Autonomous Development Protocol](M7.5%20-%20Autonomous%20Development%20Protocol.md)
  — **Canonical / M7.5 Closed**. Protocol for bounded autonomous identity,
  delegation, execution, handoff, evidence, review interaction, suspension,
  recovery, invariants, and conformance.

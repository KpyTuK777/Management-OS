# 5. Experience Amplification Dimensions

For every dimension the permitted human-owned response disposition is:
`POSITIVE`, `NEGATIVE`, `MIXED`, or `INSUFFICIENT BASIS TO JUDGE`.

1. **Attention amplification** — What, if anything, became easier to notice?
2. **Context amplification** — What relationships, if any, became easier to hold together?
3. **Temporal amplification** — What sequence or timing, if any, became easier to understand?
4. **Control-visibility amplification** — What, if anything, became clearer about operational visibility and control boundaries?
5. **Uncertainty amplification** — Which unknowns, if any, became more visible rather than falsely resolved?
6. **Distinction amplification** — Which distinctions, if any, became operationally meaningful?
7. **Judgment preparation** — Where, if anywhere, did the walkthrough better prepare human judgment without making it?
8. **Memory amplification** — What, if anything, could be re-entered or recalled more reliably because of the structured record?
9. **Counterfactual restraint** — Where, if anywhere, did the structure prevent unsupported “obvious in hindsight” conclusions?
10. **Transfer potential** — Which ways of seeing, if any, may transfer to future management situations?

No dimension assumes that amplification occurred.

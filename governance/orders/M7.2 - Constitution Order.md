# M7.2 — Constitution Order

## Status

```text
Effective / Scope bounded
```

## Ordering Authority

```text
Product Owner
```

## Authority

This repository-native order authorizes definition of the M7.2 Constitution as
the single active architecture task after canonical closure of M7.1.

## Ordered Work

Define stable constitutional foundations covering governance purpose,
constitutional authority, immutable principles, authority hierarchy, separation
of powers, invariants, amendment principles, precedence, interpretation, and
scope.

## Exclusions

This order does not authorize:

- future organizational roles or structure;
- operational workflows or review procedures;
- Development Lifecycle substance;
- autonomous execution procedures;
- implementation methodology;
- repository structure changes;
- M7.3–M7.7 work;
- approval or canonicalization of the M7.2 output.

## Completion Boundary

The order reaches its definition boundary when one implementation-independent
Constitution candidate is indexed and reports `Ready for Architecture Review`.
The order does not approve its output, and M7.2 remains Active pending the
required review lifecycle.

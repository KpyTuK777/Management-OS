# Investigation live-usage experiential findings

Date recorded: 2026-08-05
Human source: Serhii Horbachenko
Status: observational future product work; not approved implementation meaning

## Boundary

The P1 readability, optional-description, and material-icon corrections were authorized separately and are not defined here. The findings below are deliberately recorded without solution design, canonicalization, architecture, delivery commitment, or inferred authority.

## Future product findings

1. **Material-type filtering.** Large Investigations need a faster way to narrow materials by meaningful type. Exact taxonomy, interaction, and relationship to Evidence, Questions, and Hypotheses require separate Product judgment.
2. **Native file attachments.** Investigation usage needs governed attachment support for common document, image, audio, video, presentation, spreadsheet, and archive formats. Storage, security, lifecycle, limits, and persistence remain undecided.
3. **Native file viewing.** Routine inspection should remain inside the Investigation where technically feasible, with an honest fallback for unsupported formats. Viewer scope and technical boundaries remain undecided.
4. **Watson simplification.** Watson should prioritize information useful for thinking; attribution, locator, record time, and comparable implementation metadata should remain hidden unless explicitly requested. The exact human-facing information model requires separate authorization.
5. **Working Set purpose.** Live use did not reveal a clear benefit after adding an item to Working Set. This is a usability finding only. No new purpose, workflow, automation, or interaction solution is inferred.

## Non-effect

Recording these findings does not add routes, controls, filters, uploads, viewers, AI behavior, new Working Set semantics, or any canonical Product, Interaction, or Engineering meaning.
